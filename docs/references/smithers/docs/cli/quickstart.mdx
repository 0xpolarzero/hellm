title: CLI Quickstart
description: Short operational cheatsheet. The full catalog lives in CLI.
---

**Prerequisites:** `bun` installed, and a project directory where you want to run Smithers.

**Set up**

```bash
bunx smthrs init                                       # scaffold .smithers/
bunx smthrs init --template idea-to-tickets            # scaffold with guided template next steps
bunx smthrs starters                                   # browse template IDs
```

**Run**

```bash
bunx smthrs workflow run implement --prompt "…"        # launch a seeded workflow
bunx smthrs up workflow.tsx --run-id <id> --resume true   # resume a paused run
```

**Observe & control**

```bash
bunx smthrs ps                                         # list runs
bunx smthrs inspect <run-id>                           # structured run state
bunx smthrs logs <run-id> --tail 20 --follow           # stream events
bunx smthrs why <run-id>                               # why is it paused?
bunx smthrs approve <run-id> --node <id> --by <name>   # approve a paused node
bunx smthrs cancel <run-id>                            # cancel a run
```
